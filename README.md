# mts-hack-presentation

Презентация команды one-zero-eight: кейс MTS MWS CompactFactExtraction, Innopolis Global Hack, 13–16 ноября 2026.

- `index.html` — колода (открывать в браузере; `deck.js`, `data.js`, `charts.js`, `masters.css`, `fonts/`, `assets/`).
- `build_standalone.py` — сборка одного автономного HTML.
- `export_pdf.py` — экспорт в PDF через headless Chromium: `python export_pdf.py [out.pdf]` (по умолчанию `exports/deck.pdf`, 1 слайд = 1 страница).
- `pitch-business-1min.html`, `pitch.md` — бизнес-питч на 1 минуту.
- `exports/` — PDF и PNG.

Код и отчёт: https://github.com/mainStorne/mts-hack
